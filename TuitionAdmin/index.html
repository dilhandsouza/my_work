ℹ️ How It Works

  • Connect: Admin connects their Google Drive account (one-time setup)
  • Backup: Click "Backup" to save all data to your Google Drive
  • Restore: Login from another device and restore to get all data
  • Auto-sync: Data is synced automatically when you login/logout
  • Secure: Only admin can connect/disconnect. Students/Teachers unaffected

🔧 Setup Instructions

  1. Go to Google Cloud Console
  2. Create a new project or select existing one
  3. Enable "Google Drive API"
  4. Go to "OAuth consent screen" and create OAuth 2.0 credentials (Desktop app)
  5. Copy your Client ID from credentials
  6. Click "Setup Google Drive" below and paste your Client ID

⚙️ Setup Google Drive

Get it from: Google Cloud Console → Credentials → OAuth 2.0 Client IDs
